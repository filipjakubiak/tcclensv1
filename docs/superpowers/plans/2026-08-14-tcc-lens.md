# TCC Lens Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-page TCC Global landing site whose entire scroll is one continuous WebGL optical narrative — grocery doors open, a head-and-heart mark in refracting optical glass is revealed, and that mark morphs through four acts to resolve into the solid logo above the footer.

**Architecture:** Static site, no bundler. One fixed full-viewport `<canvas>` sits behind transparent DOM sections. A single Three.js renderer/scene runs one raf loop; a `SceneDirector` maps one normalized page-progress value (0→1) onto four acts, interpolating camera, lights and mark transform continuously. Acts declare keyframes and set transforms only — they never create or dispose during update, which is what makes the thread continuous rather than a sequence of cuts. GSAP + ScrollTrigger + Lenis drive DOM motion; everything gates on `prefers-reduced-motion` and `?shot=1`.

**Tech Stack:** Vanilla HTML/CSS/ESM · Three.js (current, must expose `MeshPhysicalMaterial.dispersion`) · GSAP + ScrollTrigger · Lenis · Playwright (tests + asset extraction) · sharp (image optimisation) · node:test runner

**Spec:** `docs/superpowers/specs/2026-08-14-tcc-lens-design.md` — read it alongside this plan. The plan argues from the spec; where they disagree, the spec wins except for the two refinements recorded in Global Constraints.

## Global Constraints

Every task's requirements implicitly include this section.

- **No bundler, no framework.** Plain `index.html` + `css/` + `js/` with vendored ESM. No CDN references — everything vendored locally.
- **Local server port: 4192.** (4190 = tcc-site, 4191 = tcc-lumen.)
- **All colour lives in `css/tokens.css`.** No hex literal may appear in any other CSS or JS file. Exact values:
  `--canvas #FCFCFC` · `--chamber #08070A` · `--ink #000000` · `--ink-2 #4A4E57` · `--ink-3 #7C828C` · `--accent #D380EB` · `--support #B1BDCE` · `--hairline rgba(0,0,0,0.10)` · `--hairline-inv rgba(252,252,252,0.14)`
- **Capability gradients** (never combined, one per section max, always paired with black/white/photography):
  Performance `#FFADBD`→`#CFD0F7` · Insight `#B7F4E6`→`#CFD0F7` · Creativity `#FDFFCF`→`#F8C1F7` · Operational Excellence `#FFC896`→`#D9CAF6` · Sustainability `#B7F4E6`→`#E6F5A9`
- **`--accent` is never body text.** Fills, underlines, 3D lighting and single focal words only. All reading text is `--ink` or the grey ramp.
- **Body copy hard cap: 18px (`1.125rem`).** Violating this collapses the editorial rhythm.
- **Typeface: Neue Plak only.** Bold 700 display, SemiBold 600 most communication, Regular 400 body. No second display face.
- **Tagline `Inspiring loyalty. Creating value.` must always appear as the whole phrase.** Never use half in isolation.
- **All motion gates on `prefers-reduced-motion: reduce` AND `?shot=1`.** Under either, the page renders in its final settled state — never blank, never mid-transition.
- **Buttons are fully-rounded pills** with purple-tinted shadow `0 8px 20px rgba(148,44,181,0.38)`. Never grey shadow, never sharp corners.
- **Grain is a PNG overlay**, never an SVG filter (SVG filters destroy scroll performance).
- **REFINEMENT vs spec §11 — only `LensMark` uses `transmission`.** The doors in Act 1 use reflective envmap glass (transparent + high reflectivity, no transmission pass). Keeps the "exactly one transmissive object" budget and is more truthful: store doors at night read as reflective, not clear.
- **REFINEMENT vs spec §4 — doors are sliding, not hinged.**
- Image treatment: de-saturate, avoid faces where possible. **Do not reproduce the colour grading of the example images inside the brand PDF — it is outdated.**

Create `tools/serve.mjs`. No dependencies — tests must be able to boot it programmatically.

```js
import http from 'node:http';
import { createReadStream } from 'node:fs';
import { stat } from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');

const TYPES = {
  '.html': 'text/html; charset=utf-8',
  '.css': 'text/css; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.mjs': 'text/javascript; charset=utf-8',
  '.json': 'application/json',
  '.svg': 'image/svg+xml',
  '.png': 'image/png',
  '.jpg': 'image/jpeg',
  '.jpeg': 'image/jpeg',
  '.webp': 'image/webp',
  '.avif': 'image/avif',
  '.mp4': 'video/mp4',
  '.woff2': 'font/woff2',
  '.ttf': 'font/ttf',
};

export function startServer(port = 4192) {
  const server = http.createServer(async (req, res) => {
    const urlPath = decodeURIComponent(new URL(req.url, 'http://x').pathname);
    let filePath = path.join(ROOT, urlPath === '/' ? 'index.html' : urlPath);

    if (!filePath.startsWith(ROOT)) {
      res.writeHead(403).end('Forbidden');
      return;
    }
    try {
      const info = await stat(filePath);
      if (info.isDirectory()) filePath = path.join(filePath, 'index.html');
    } catch {
      res.writeHead(404).end('Not found');
      return;
    }
    res.writeHead(200, {
      'Content-Type': TYPES[path.extname(filePath).toLowerCase()] ?? 'application/octet-stream',
      'Cache-Control': 'no-store',
    });
    createReadStream(filePath).pipe(res);
  });

  return new Promise((resolve) => {
    server.listen(port, () => {
      resolve({
        url: `http://localhost:${port}`,
        close: () => new Promise((r) => server.close(r)),
      });
    });
  });
}

if (import.meta.url === `file://${process.argv[1].replace(/\\/g, '/')}`) {
  const { url } = await startServer(Number(process.argv[2]) || 4192);
  console.log(`TCC Lens serving at ${url}`);
}
```

```js
import { chromium } from 'playwright';
import { startServer } from '../serve.mjs';

let port = 4300;

export async function withPage(fn, query = '') {
  const server = await startServer(port++);
  const browser = await chromium.launch();
  const page = await browser.newPage({ viewport: { width: 1440, height: 900 } });
  try {
    await page.goto(server.url + query, { waitUntil: 'load' });
    return await fn(page);
  } finally {
    await browser.close();
    await server.close();
  }
}

/** Read a CSS custom property off :root as a trimmed string. */
export const cssVar = (page, name) =>
  page.evaluate(
    (n) => getComputedStyle(document.documentElement).getPropertyValue(n).trim(),
    name
  );
```

```js
import sharp from 'sharp';
import { readdir, mkdir } from 'node:fs/promises';
import path from 'node:path';

const SRC = '../assets/img';
const OUT = '../assets/img/optimized';
const WIDTHS = [640, 1024, 1600];
const RASTER = /\.(png|jpe?g)$/i;

async function* walk(dir) {
  for (const e of await readdir(dir, { withFileTypes: true })) {
    if (e.name === 'optimized') continue;
    const p = path.join(dir, e.name);
    if (e.isDirectory()) yield* walk(p);
    else if (RASTER.test(e.name)) yield p;
  }
}

await mkdir(OUT, { recursive: true });
let n = 0;
for await (const file of walk(SRC)) {
  const base = path.basename(file).replace(RASTER, '');
  const meta = await sharp(file).metadata();
  for (const w of WIDTHS) {
    if (meta.width && meta.width < w) continue;
    const pipe = sharp(file).resize({ width: w, withoutEnlargement: true });
    await pipe.clone().avif({ quality: 55 }).toFile(`${OUT}/${base}-${w}.avif`);
    await pipe.clone().webp({ quality: 78 }).toFile(`${OUT}/${base}-${w}.webp`);
    n += 2;
  }
}
console.log(`wrote ${n} derivatives`);
```

```js
export function initNav() {
  const nav = document.querySelector('.nav');
  if (!nav) return;

  const sync = () => {
    nav.classList.toggle('nav--solid', window.scrollY > window.innerHeight * 0.85);
  };
  sync();
  window.addEventListener('scroll', sync, { passive: true });

  const menu = document.querySelector('.menu');
  const burger = document.querySelector('.nav__burger');
  if (!menu || !burger) return;

  const setOpen = (open) => {
    menu.classList.toggle('is-open', open);
    menu.setAttribute('aria-hidden', String(!open));
    burger.setAttribute('aria-expanded', String(open));
    document.body.style.overflow = open ? 'hidden' : '';
    if (open) menu.querySelector('a')?.focus();
    else burger.focus();
  };

  burger.addEventListener('click', () => setOpen(!menu.classList.contains('is-open')));
  document.addEventListener('keydown', (e) => {
    if (e.key === 'Escape' && menu.classList.contains('is-open')) setOpen(false);
  });
}
```

- [ ] **Step 4: Write `js/motion/reveal.js`**

```js
export function motionEnabled() {
  const shot = new URLSearchParams(location.search).get('shot') === '1';
  const reduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  return !shot && !reduced;
}

export function initLenis() {
  if (!motionEnabled()) return null;
  const lenis = new window.Lenis({ duration: 1.1, smoothWheel: true });
  const raf = (t) => { lenis.raf(t); requestAnimationFrame(raf); };
  requestAnimationFrame(raf);
  lenis.on('scroll', window.ScrollTrigger.update);
  return lenis;
}

export function initReveals() {
  if (!motionEnabled()) return;
  const { gsap, ScrollTrigger } = window;
  gsap.registerPlugin(ScrollTrigger);
  document.documentElement.classList.add('motion-on');

  // The signature: text arrives out of focus and resolves sharp.
  gsap.utils.toArray('[data-focus-pull]').forEach((el) => {
    gsap.to(el, {
      opacity: 1, filter: 'blur(0px)', scale: 1,
      duration: 0.9, ease: 'expo.out',
      scrollTrigger: { trigger: el, start: 'top 85%', once: true },
    });
  });

  // Masked line reveals, staggered.
  gsap.utils.toArray('[data-focus-pull]').forEach((el) => {
    const lines = el.querySelectorAll('.line > span');
    if (!lines.length) return;
    gsap.to(lines, {
      y: '0%', duration: 0.9, ease: 'expo.out', stagger: 0.06,
      scrollTrigger: { trigger: el, start: 'top 85%', once: true },
    });
  });
}
```

```js
export function initCounters() {
  const nodes = document.querySelectorAll('[data-count-to]');
  const final = (el) => el.dataset.countTo + (el.dataset.suffix ?? '');

  if (!motionEnabled()) {
    nodes.forEach((el) => { el.textContent = final(el); });
    return;
  }

  const { gsap } = window;
  nodes.forEach((el) => {
    const target = Number(el.dataset.countTo);
    const suffix = el.dataset.suffix ?? '';
    const box = { v: 0 };
    gsap.to(box, {
      v: target, duration: 1.6, ease: 'expo.out',
      onUpdate: () => { el.textContent = Math.round(box.v) + suffix; },
      onComplete: () => { el.textContent = final(el); },
      scrollTrigger: { trigger: el, start: 'top 88%', once: true },
    });
  });
}
```

```js
import { motionEnabled } from './reveal.js';

export function initCursor() {
  if (!motionEnabled()) return;
  if (!window.matchMedia('(pointer: fine)').matches) return;

  const dot = document.createElement('div');
  dot.className = 'cursor';
  dot.setAttribute('aria-hidden', 'true');
  document.body.appendChild(dot);

  const { gsap } = window;
  const move = gsap.quickTo(dot, 'x', { duration: 0.25, ease: 'power3' });
  const moveY = gsap.quickTo(dot, 'y', { duration: 0.25, ease: 'power3' });
  window.addEventListener('pointermove', (e) => { move(e.clientX); moveY(e.clientY); });

  document.querySelectorAll('a, button, [data-magnetic]').forEach((el) => {
    el.addEventListener('pointerenter', () => dot.classList.add('cursor--swell'));
    el.addEventListener('pointerleave', () => dot.classList.remove('cursor--swell'));
  });
}

export function initMagnetic() {
  if (!motionEnabled()) return;
  if (!window.matchMedia('(pointer: fine)').matches) return;
  const { gsap } = window;
  const MAX = 8;

  document.querySelectorAll('[data-magnetic]').forEach((el) => {
    el.addEventListener('pointermove', (e) => {
      const r = el.getBoundingClientRect();
      const dx = ((e.clientX - (r.left + r.width / 2)) / (r.width / 2)) * MAX;
      const dy = ((e.clientY - (r.top + r.height / 2)) / (r.height / 2)) * MAX;
      gsap.to(el, { x: dx, y: dy, duration: 0.4, ease: 'power3.out' });
    });
    el.addEventListener('pointerleave', () => {
      gsap.to(el, { x: 0, y: 0, duration: 0.5, ease: 'elastic.out(1, 0.6)', overwrite: true });
    });
  });
}
```

Note: `elastic` is used only for the magnetic *release* — a pointer-tracking spring-back, not an entrance animation. The spec's ban on elastic covers entrances.

```js
import * as THREE from '../vendor/three.module.js';

export function createStage() {
  const canvas = document.getElementById('stage');
  if (!canvas) return null;

  let renderer;
  try {
    renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: false, powerPreference: 'high-performance' });
  } catch {
    return null;   // no WebGL — Task 17 installs the poster fallback
  }

  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 1.75));
  renderer.setSize(window.innerWidth, window.innerHeight, false);
  renderer.toneMapping = THREE.ACESFilmicToneMapping;
  renderer.toneMappingExposure = 1.05;

  const scene = new THREE.Scene();
  scene.background = new THREE.Color(0x08070A);   // --chamber

  const camera = new THREE.PerspectiveCamera(38, window.innerWidth / window.innerHeight, 0.1, 100);
  camera.position.set(0, 0, 8);

  const clock = new THREE.Clock();
  const updaters = [];
  let raf = 0;
  let frames = 0;

  const stage = { THREE, scene, camera, renderer, clock, frames: 0, addUpdater, dispose };

  function addUpdater(fn) { updaters.push(fn); }

  function frame() {
    raf = requestAnimationFrame(frame);
    const dt = clock.getDelta();
    const t = clock.elapsedTime;
    for (const fn of updaters) fn(t, dt);
    renderer.render(scene, camera);
    stage.frames = ++frames;
  }

  function start() { if (!raf) { clock.getDelta(); raf = requestAnimationFrame(frame); } }
  function stop()  { cancelAnimationFrame(raf); raf = 0; }

  document.addEventListener('visibilitychange', () => {
    document.visibilityState === 'hidden' ? stop() : start();
  });

  let resizeTimer;
  window.addEventListener('resize', () => {
    clearTimeout(resizeTimer);
    resizeTimer = setTimeout(() => {
      camera.aspect = window.innerWidth / window.innerHeight;
      camera.updateProjectionMatrix();
      renderer.setPixelRatio(Math.min(window.devicePixelRatio, 1.75));
      renderer.setSize(window.innerWidth, window.innerHeight, false);
    }, 120);
  }, { passive: true });

  function dispose() {
    stop();
    scene.traverse((o) => { o.geometry?.dispose?.(); 
      if (Array.isArray(o.material)) o.material.forEach((m) => m.dispose()); else o.material?.dispose?.(); });
    renderer.dispose();
  }

  start();
  window.__tccStage = stage;
  return stage;
}
```

```js
import * as THREE from '../vendor/three.module.js';

export function buildEnvironment(stage, { from = 0xD380EB, to = 0xB1BDCE } = {}) {
  const size = 512;
  const canvas = document.createElement('canvas');
  canvas.width = canvas.height = size;
  const ctx = canvas.getContext('2d');

  const texture = new THREE.CanvasTexture(canvas);
  texture.mapping = THREE.EquirectangularReflectionMapping;
  texture.colorSpace = THREE.SRGBColorSpace;

  const pmrem = new THREE.PMREMGenerator(stage.renderer);
  pmrem.compileEquirectangularShader();
  let envRT = null;

  const hex = (n) => '#' + n.toString(16).padStart(6, '0');

  function paint(f, t) {
    const g = ctx.createLinearGradient(0, 0, 0, size);
    g.addColorStop(0, hex(f));
    g.addColorStop(0.55, hex(t));
    g.addColorStop(1, '#08070A');            // --chamber floor
    ctx.fillStyle = g;
    ctx.fillRect(0, 0, size, size);

    // Two soft highlights give the glass something to catch and streak.
    for (const [x, y, r, a] of [[size * 0.28, size * 0.22, size * 0.16, 0.85],
                                [size * 0.74, size * 0.34, size * 0.10, 0.5]]) {
      const s = ctx.createRadialGradient(x, y, 0, x, y, r);
      s.addColorStop(0, `rgba(255,255,255,${a})`);
      s.addColorStop(1, 'rgba(255,255,255,0)');
      ctx.fillStyle = s;
      ctx.fillRect(0, 0, size, size);
    }
    texture.needsUpdate = true;

    envRT?.dispose();
    envRT = pmrem.fromEquirectangular(texture);
    stage.scene.environment = envRT.texture;
  }

  paint(from, to);
  return { texture, setTint: paint };
}
```

- [ ] **Step 4: Write `js/stage/LensMark.js`**

`logo-icon.svg` contains exactly two paths — the head circle and the heart — which is what makes Act 2's separation possible. SVG Y grows downward and Three's grows upward, so the group is flipped on Y.

```js
import * as THREE from '../vendor/three.module.js';
import { SVGLoader } from '../vendor/SVGLoader.js';

const EXTRUDE = {
  depth: 0.62,          // real thickness — thin extrusion reads as plastic
  bevelEnabled: true,
  bevelThickness: 0.09, // the bevel is what makes it read as glass
  bevelSize: 0.07,
  bevelSegments: 6,
  curveSegments: 48,
};

export async function createLensMark(stage) {
  const svg = await new SVGLoader().loadAsync('assets/img/logo-icon.svg');

  const material = new THREE.MeshPhysicalMaterial({
    transmission: 1.0,
    thickness: 2.4,
    ior: 1.52,
    dispersion: 4.0,
    roughness: 0.04,
    metalness: 0.0,
    iridescence: 0.25,
    clearcoat: 1.0,
    clearcoatRoughness: 0.03,
    color: 0xffffff,
  });

  const meshFor = (path) => {
    const geo = new THREE.ExtrudeGeometry(SVGLoader.createShapes(path), EXTRUDE);
    geo.computeVertexNormals();
    return new THREE.Mesh(geo, material);
  };

  // paths[0] = head circle, paths[1] = heart
  const head = meshFor(svg.paths[0]);
  const heart = meshFor(svg.paths[1]);

  const group = new THREE.Group();
  group.add(head, heart);
  group.scale.y *= -1;             // SVG Y-down → Three Y-up

  // Centre on the origin and normalise to ~2 world units tall.
  const box = new THREE.Box3().setFromObject(group);
  const size = box.getSize(new THREE.Vector3());
  const centre = box.getCenter(new THREE.Vector3());
  group.children.forEach((m) => m.position.sub(centre.clone().multiply(new THREE.Vector3(1, -1, 1))));

  const inner = new THREE.Group();
  inner.add(group);
  inner.scale.setScalar(2 / size.y);

  const lens = {
    group: inner, head, heart, material,
    setTransmission(v) { material.transmission = v; material.needsUpdate = true; },
  };

  stage.scene.add(inner);
  window.__tccLens = lens;
  return lens;
}
```

```js
const clamp01 = (v) => Math.min(1, Math.max(0, v));

export function createDirector(stage, ctx) {
  const acts = [];
  let progress = 0;
  let active = null;

  const director = {
    get progress() { return progress; },
    get activeAct() { return active; },
    register, setProgress, attachScroll,
  };

  function register(act) {
    act._t = 0;
    act.build?.(ctx);
    acts.push(act);
    acts.sort((a, b) => a.range[0] - b.range[0]);
    return director;
  }

  function actAt(p) {
    // Last act whose start <= p; the final act owns p === 1.
    let found = acts[0];
    for (const a of acts) if (p >= a.range[0]) found = a;
    return found;
  }

  function setProgress(p) {
    progress = clamp01(p);
    const next = actAt(progress);
    if (next !== active) {
      active?.exit?.(ctx);
      active = next;
      active?.enter?.(ctx);
    }
    const [s, e] = active.range;
    active._t = e === s ? 1 : clamp01((progress - s) / (e - s));
    active.update?.(active._t, ctx);
  }

  function attachScroll() {
    const { gsap, ScrollTrigger } = window;
    gsap.registerPlugin(ScrollTrigger);
    ScrollTrigger.create({
      trigger: document.body,
      start: 'top top',
      end: 'bottom bottom',
      scrub: 1,
      onUpdate: (self) => setProgress(self.progress),
    });
  }

  window.__tccDirector = director;
  return director;
}

export function mountDebugScrub(director) {
  if (new URLSearchParams(location.search).get('debug') !== '1') return;

  const box = document.createElement('div');
  box.id = 'tcc-debug';
  box.style.cssText =
    'position:fixed;left:16px;bottom:16px;z-index:999;background:#000;color:#fff;' +
    'padding:10px 14px;border-radius:999px;font:11px/1 monospace;display:flex;gap:10px;align-items:center';
  box.innerHTML =
    '<input type="range" min="0" max="1000" value="0" style="width:280px"><span>0.000 · —</span>';
  document.body.appendChild(box);

  const [slider, label] = [box.querySelector('input'), box.querySelector('span')];

    const p = slider.valueAsNumber / 1000;
    director.setProgress(p);

  });
}
```

```js
import * as THREE from '../../vendor/three.module.js';

const lerp = (a, b, t) => a + (b - a) * t;

// The environment tint follows whichever capability is in view — the prism
// splits brand light into the brand's own five-gradient spectrum.
const SPECTRUM = {
  performance:    [0xFFADBD, 0xCFD0F7],
  insight:        [0xB7F4E6, 0xCFD0F7],
  creativity:     [0xFDFFCF, 0xF8C1F7],
  operational:    [0xFFC896, 0xD9CAF6],
  sustainability: [0xB7F4E6, 0xE6F5A9],
};
const ORDER = Object.keys(SPECTRUM);

let observer, current = null;

function tintFor(name, ctx) {
  const pair = SPECTRUM[name];
  if (!pair || name === current) return;
  current = name;
  ctx.env.setTint(pair[0], pair[1]);
}

export default {
  id: 'prism',
  range: [0.55, 0.82],

  build(ctx) {
    const cards = document.querySelectorAll('#capabilities .capability');
    observer = new IntersectionObserver(
      (entries) => {
        const hit = entries.filter((e) => e.isIntersecting)
                           .sort((a, b) => b.intersectionRatio - a.intersectionRatio)[0];
        if (hit) tintFor(hit.target.dataset.gradient, ctx);
      },
      { threshold: [0.3, 0.6, 0.9] }
    );
    cards.forEach((c) => observer.observe(c));
    window.__tccAct3 = { tintFor: (n) => tintFor(n, ctx), SPECTRUM, ORDER };
  },

  update(t, ctx) {
    const { stage, lens } = ctx;

    // Halves recombine.
    const join = 1 - THREE.MathUtils.smoothstep(t, 0.0, 0.32);
    lens.head.position.x = -1.55 * join;
    lens.heart.position.x = 1.55 * join;
    lens.head.position.y = 0.35 * join;
    lens.heart.position.y = -0.35 * join;
    lens.head.rotation.y = 0;
    lens.heart.rotation.y = 0;

    // Then the whole mark rotates edge-on — it becomes a prism slab.
    const edge = THREE.MathUtils.smoothstep(t, 0.28, 0.72);
    lens.group.rotation.y = edge * (Math.PI / 2) * 1.18;
    lens.group.rotation.z = edge * 0.14;
    lens.group.position.x = lerp(0, 0.9, edge);

    // Thicker glass at the edge-on angle exaggerates the split.
    lens.material.thickness = lerp(2.4, 5.2, edge);
    lens.material.dispersion = lerp(4.0, 7.5, edge);

    stage.camera.position.z = lerp(5.6, 4.4, t);
    stage.camera.position.x = lerp(0, -0.8, edge);
    stage.camera.lookAt(0, 0, 0);
  },

  exit(ctx) {
    ctx.lens.material.thickness = 2.4;
    ctx.lens.material.dispersion = 4.0;
    ctx.env.setTint(0xD380EB, 0xB1BDCE);   // back to TCC Core
    current = null;
  },
};
```

```js
import * as THREE from '../../vendor/three.module.js';

const lerp = (a, b, t) => a + (b - a) * t;

export default {
  id: 'close',
  range: [0.82, 1.0],

  build(ctx) { window.__tccAct4 = {}; },

  update(t, ctx) {
    const { stage, lens } = ctx;
    const s = THREE.MathUtils.smoothstep(t, 0, 1);

    // Square up: out of the prism angle, back to face-on.
    lens.group.rotation.y = lerp(Math.PI / 2 * 1.18, 0, THREE.MathUtils.smoothstep(t, 0, 0.5));
    lens.group.rotation.z = lerp(0.14, 0, THREE.MathUtils.smoothstep(t, 0, 0.5));
    lens.group.position.x = lerp(0.9, 0, THREE.MathUtils.smoothstep(t, 0, 0.5));

    // Halves fully rejoin.
    lens.head.position.set(0, 0, 0);
    lens.heart.position.set(0, 0, 0);

    // Recede and settle where a logo belongs.
    lens.group.scale.setScalar(lerp(1, 0.34, s));
    lens.group.position.y = lerp(0, 0.5, s);

    // Glass becomes solid — refraction resolves into clarity.
    const solid = THREE.MathUtils.smoothstep(t, 0.45, 0.95);
    lens.setTransmission(1 - solid);
    lens.material.thickness = lerp(2.4, 0.4, solid);
    lens.material.roughness = lerp(0.04, 0.32, solid);
    lens.material.color.setHex(0xFCFCFC);       // --canvas; reads as the flat mark
    lens.material.metalness = solid * 0.15;

    stage.camera.position.set(0, 0, lerp(4.4, 6.2, s));
    stage.camera.lookAt(0, 0.3, 0);
  },
};
```

```js
export function detectTier() {
  const canvas = document.createElement('canvas');
  const gl = canvas.getContext('webgl2') || canvas.getContext('webgl');
  if (!gl) return 'none';

  const lowMemory = (navigator.deviceMemory ?? 8) < 4;
  const fewCores = (navigator.hardwareConcurrency ?? 8) <= 4;
  const narrow = window.innerWidth < 860;

  return lowMemory || fewCores || narrow ? 'lite' : 'full';
}
```
